# Planner on phone/tablet (installable web app)
Host these files over HTTPS (see steps in chat), open the URL on your phone, then:
- Android (Chrome): menu > Install app / Add to Home screen
- iPhone/iPad (Safari): Share > Add to Home Screen
Data stays on the device. Phone reminders fire only while the app is open (OS limit for web apps).
Use Settings > Export backup regularly; Import backup moves data between devices.
